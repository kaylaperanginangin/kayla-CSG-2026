# Comics Study Group — Fisika Kuantum

Repositori ini berisi dokumentasi pengerjaan tugas dan kode simulasi untuk program **Comics Study Group: Fisika Kuantum**. Fokus materi mencakup pemahaman konsep transisi dari fisika klasik menuju mekanika kuantum, perhitungan fisis, hingga implementasi visualisasi berbasis komputasi numerik.

---
